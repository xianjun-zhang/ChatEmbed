💬 Chatbot Bubble - Demo

Bubble Demo: This page demonstrates the bubble chatbot embed - a floating widget that appears as a chat bubble on your website. Perfect for customer support and engagement!

Bubble Chatbot Demo

The bubble chatbot appears as a floating button (usually in the bottom-right corner). Click it to start chatting!

🎯 Look for the chat bubble in the bottom-right corner!
(The bubble chatbot will initialize automatically)

Integration Code

To add the bubble chatbot to your website, use this code:

<script type="module"> import Chatbot from 'https://cdn.jsdelivr.net/npm/bitflow-chatbot-embed/dist/web.js'; // Note: Chatbot.init() creates the bubble element automatically // No need for <n-chatbot> element in HTML Chatbot.init({ chatflowid: 'your-chatflow-id', apiHost: 'https://your-api-host.com', theme: { button: { backgroundColor: '#3B81F6', right: 20, bottom: 20, size: 'medium', iconColor: 'white' }, chatWindow: { title: 'Chat with us!', backgroundColor: '#ffffff' } } }); </script>

Bubble vs Full Chatbot

🫧 Bubble Chatbot

  • Floating chat button
  • Minimal screen space
  • Perfect for websites
  • Non-intrusive design
  • Expandable chat window

📱 Full Chatbot

  • Embedded in page content
  • Takes dedicated space
  • Perfect for dedicated chat pages
  • Always visible interface
  • Full-featured display
